# Análise de Dados com SQL

Este projeto contém consultas SQL básicas para análise de dados de vendas.

## Objetivo
Praticar consultas SQL para extrair informações relevantes de um banco de dados.

## Consultas realizadas
- Seleção de dados
- Agrupamento por produto
- Contagem de pedidos por cliente

## Tecnologias
- SQL
